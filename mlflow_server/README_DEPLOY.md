# Deploy MLflow UI no Render

1. No dashboard do Render, criar novo **Web Service**
2. Conectar ao mesmo repositório GitHub
3. Configurações:
   - **Name:** agile-estimator-mlflow
   - **Root Directory:** (deixar vazio — raiz do repo)
   - **Dockerfile Path:** mlflow_server/Dockerfile
   - **Instance Type:** Free
4. Clicar em Deploy
5. URL gerada: https://agile-estimator-mlflow.onrender.com
